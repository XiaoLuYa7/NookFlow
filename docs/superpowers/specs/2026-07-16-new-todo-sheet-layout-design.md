# 新建待办弹窗布局与属性一致性设计

## 目标

设置窗口中的“新建待办”应与灵动岛创建入口具备相同的任务属性，并以更清晰的纵向信息层级展示日期与时间。

## 交互与布局

- 弹窗宽度保持 `520pt`，不扩大窗口。
- 任务内容区域保持现状。
- 在任务内容与日期时间之间新增“任务属性”卡片：
  - “分组”使用 `TodoCategory`，默认“无”。
  - “优先级”使用 `TodoPriority`，默认“普通”。
- 日期时间卡片改为两个全宽设置行：
  - 日期行左侧显示标题与说明，右侧使用紧凑的年、月、日数字输入框，不显示长下拉菜单。
  - 年最多输入 4 位，月、日最多输入 2 位，只接受数字；合法日期实时更新，非法日期阻止保存。
  - 时间行左侧显示标题与说明，右侧直接显示“上午 / 中午 / 下午 / 晚上 / 自定义”快捷选项。
  - “自定义”选项内部直接显示小时、分钟数字输入框，不增加第二行，也不使用系统紧凑 `DatePicker`。
  - 点击其他时间项、设置控件或弹窗空白区域时结束数字输入焦点，但保留输入值。
- 删除独立的“快捷时间”标题和单独占行区域。
- 到期提醒、位置和底部操作保持原有功能。

## 数据一致性

- `TodoTaskDraft` 增加 `category` 与 `priority`，默认值与灵动岛一致。
- 设置窗口保存草稿时写入当前分组和优先级。
- 本地任务创建时保留这两个字段。
- 创建系统提醒事项时复用 `TodoCategory.tagText` 与 `TodoPriority.tagText` 生成标签，确保重新同步后仍能恢复属性。

## 范围限制

- 不修改灵动岛新建待办布局。
- 不修改待办卡片设置、日期筛选和提醒事项同步流程。
- 点击失焦监听只在新建待办弹窗存在时注册，弹窗销毁时立即移除。
- 不启动 NookFlow；仅运行聚焦测试、源码检查与 Debug 编译。

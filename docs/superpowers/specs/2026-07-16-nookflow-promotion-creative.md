# NookFlow 推广素材创意方案

## 目标

面向音乐与桌面美化用户，建立 NookFlow 的审美印象，并引导用户下载试用。素材覆盖小红书、抖音、B 站、App Store 与官网等渠道，仅使用简体中文。

## 创意核心

主题为“让音乐留在桌面上”。NookFlow 在需要时从刘海区域自然展开，展示音乐、歌词和常用信息；不需要时安静退场。视觉采用已确认的 A“原生日常”方向：明亮但不发白，真实 macOS 桌面为背景，青绿、雾蓝与暖金仅用于局部点缀。

高级感来自真实材质、自然光线、克制留白、精确排版与细腻过渡。禁止使用重度黑底、夸张渐变、发光特效、虚构产品 UI 或浮夸科技元素。

## 素材交付

1. 主宣传图：以真实 NookFlow 界面和 macOS 桌面为主体，作为整套视觉锚点。
2. 跨平台静态图：交付 9:16、4:5、1:1 与 16:9 四种构图。四张分别强调音乐歌词、桌面氛围、轻量效率与产品整体印象。
3. 视频分镜和剪辑脚本：12 至 15 秒竖版，包含每秒画面、屏幕文字、转场和音乐情绪说明，可直接在剪映或 Final Cut 中制作。
4. 发布文案包：小红书标题与正文、抖音/B 站标题与描述、官网/App Store 简介。

图片不固化下载链接，以免链接变化导致失效。发布正文保留链接位；统一行动文案为“下载 NookFlow，试试看。”

## 文案体系

主文案：

> 音乐在流动，桌面也该有自己的节奏。

副文案：

> NookFlow 让歌词、播放控制和常用信息自然停留在刘海附近。需要时展开，不需要时安静退场。

行动文案：

> 下载 NookFlow，试试看。

## 视频分镜

| 时长 | 画面 | 屏幕文字 | 动效与声音 |
| --- | --- | --- | --- |
| 0-3 秒 | 干净的 macOS 桌面，音乐开始播放，刘海区域亮起。 | 音乐在流动 | 柔和的前奏，轻微呼吸式亮起。 |
| 3-7 秒 | 灵动岛平滑展开，显现封面、歌曲和同步歌词。 | 让歌词留在桌面上 | 连续、克制的展开动效。 |
| 7-11 秒 | 天气、待办、快捷应用依次短暂出现。 | 常用信息，自然出现 | 轻快但不跳跃的模块切换。 |
| 11-15 秒 | 回到整洁桌面，出现 NookFlow 图标和行动文案。 | 下载 NookFlow，试试看。 | 音乐收束，界面自然收起。 |

## 约束与验收

- 所有内容使用简体中文，不使用不可验证的性能、价格或兼容性承诺。
- 所有产品界面必须来源于当前 NookFlow 应用的真实画面；生成式图片只用于桌面环境、光线和辅助氛围，不取代产品 UI。
- 每种画幅需在不裁掉主文案、刘海区域或下载引导的前提下独立构图。
- 任何截图都应能在明亮与深色背景中看清文字和产品边界。
- 视频脚本提供静音也可理解的屏幕文字，并以合法可商用音乐为前提。

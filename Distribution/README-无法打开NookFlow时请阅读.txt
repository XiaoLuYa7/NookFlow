NookFlow 安装与首次打开说明
========================

请放心：从 NookFlow 官网下载的安装包不包含恶意程序，不会在后台窃取、出售或用于广告追踪您的个人信息。macOS 出现“Apple 无法验证”的提示，是因为当前官网版本尚未使用 Apple Developer ID 完成公证，并不代表系统已经检测到病毒或恶意行为。

NookFlow 采用“本地优先”方式工作。应用列表、待办事项、文件入口、界面偏好等内容主要保存在您的 Mac 上。当前版本不包含广告 SDK，也不进行跨应用行为追踪。

如果双击 NookFlow 后出现“未打开 NookFlow”或“Apple 无法验证 NookFlow 是否包含可能危害 Mac 安全或泄漏隐私的恶意软件”的提示，请按以下步骤操作：

1. 先将本安装窗口中的 NookFlow 拖入“Applications（应用程序）”文件夹。
2. 打开“系统设置”。
3. 进入“隐私与安全性”。
4. 向下滚动到“安全性”区域。
5. 找到“已阻止使用 NookFlow 以保护 Mac”的提示，点击“仍要打开”。
6. 系统再次弹出确认窗口后，再点击“仍要打开”。
7. 使用 Touch ID（指纹）或输入 Mac 登录密码完成确认。
8. 回到“应用程序”文件夹重新打开 NookFlow，之后即可正常使用。

说明：
- 以上操作通常只需要在首次打开当前版本时进行一次。
- 请仅从 NookFlow 官网下载应用，避免使用来源不明的安装包。
- 如果“安全性”区域没有出现“仍要打开”，请先在“应用程序”文件夹中双击 NookFlow 一次，再返回此页面查看。

隐私与权限说明
--------------

NookFlow 只会在您使用对应功能时申请必要权限，拒绝某项权限不会影响无关功能：

- 定位：用于查询当前位置天气。天气功能会向 Open-Meteo 发送近似经纬度以获取天气数据。
- 日历与提醒事项：用于在卡片中读取或管理您选择展示的日程、待办数据，数据通过 macOS 官方框架访问。
- 摄像头：仅在您手动点击“开启镜子”后显示实时画面；画面不会由 NookFlow 保存或上传，关闭镜子后会停止摄像头会话。
- 文件：仅访问您主动选择、拖入或授权的文件与目录，不会扫描未获授权的位置。
- 自动化与媒体控制：用于读取或控制 Apple Music、Spotify 等播放器的播放状态；只有启用相关功能时才使用。
- 通知：仅用于您开启的提醒和应用状态提示。

以下联网行为只在对应功能需要时发生：天气查询、歌词与封面匹配、软件更新检查，以及 Pro 激活与订单验证。购买 Pro 时，服务器会保存订单联系邮箱、支付状态和许可验证所需的设备公钥摘要；不会读取 Mac 硬件序列号，也不会发送营销邮件。

您可以随时在 NookFlow 设置中关闭相关功能，或前往“系统设置 → 隐私与安全性”撤回已经授予的权限。撤回后，对应功能将停止访问相关数据。

如果您对权限、隐私或安装来源仍有疑问，请先不要继续授权，并通过官网联系开发者核实。
